# 화면 구조와 주요 사용 흐름 (구현 전 설계)

## 화면 목록

1. **워크벤치** (`/`, 기본) — 문서 탐색 + 문서 보기 + 질문·검토
2. **연구 결과** (`/#research`) — 모델 비교, 강화학습, 추론 최적화, 멀티 GPU 실험 결과와 조건
3. **API 문서** (`/docs`, FastAPI 자동 문서; 실시간 모드에서만)

## 워크벤치 레이아웃

```
┌──────────────────────────────────────────────────────────────────────────┐
│ TableTrace  표·문서 근거 검증 워크벤치     [한국어 표|영어 화학]  ● 실시간 실행 │
│ 처음이세요? ① 문서 선택 → ② 질문 입력/대표 질문 → ③ 검색·도구 실행 → ④ 근거 검토  [닫기] │
├──────────────┬───────────────────────────────┬───────────────────────────┤
│ 문서 (검색)  │ 문서 제목 · 출처 · 라이선스     │ 질문                      │
│ ▸ 문서 A     │ 본문 문단 … (근거 문장 하이라이트) │ [입력창            ] [실행] │
│   표 1       │                               │ 플래너: 자동|신경망|휴리스틱 │
│ ▸ 문서 B     │ 표 1  (r/c 좌표, 단위)          │ 상태: 실행 중 · 1,240 ms   │
│   …          │  ┌──┬──┬──┐  근거 셀 ①②        │ ─────────────────────────│
│ 대표 질문     │  │  │  │  │                   │ 답변  1,062,201 명   [완료] │
│  · 셀 근거    │  └──┴──┴──┘                   │ 근거 ① r0c4 12,274,031 명 │
│  · 계산      │                               │      ② r1c4 11,211,830 명 │
│  · 본문+표   │                               │ 계산  12274031 − 11211830  │
│  · 단위·기간  │                               │ 검사  ✓ 셀 범위 ✓ 단위 ✓ … │
│  · 답 없음    │                               │ 추적  retrieve 3ms → …     │
└──────────────┴───────────────────────────────┴───────────────────────────┘
```

- 데스크톱(≥ 1000px): 3열(260 / 가변 / 400). 가운데·오른쪽은 각각 독립 스크롤.
- 모바일(< 1000px): 상단 탭 `문서 | 질문·결과`. 표는 가로 스크롤 컨테이너.

## 주요 사용 흐름

1. 진입 → 코퍼스 선택(기본: 한국어 표) → 왼쪽 문서 목록에서 문서 클릭 → 가운데에 본문·표 표시.
2. 대표 질문 칩 클릭(또는 직접 입력 + Enter) → 오른쪽 상태 `대기 → 실행 중` → 완료.
3. 답변 카드: 상태(완료/보류/오류), 답변, 근거(셀 번호 배지 / 문장), 계산식(값·단위), 검사 목록, 실행 추적.
4. 근거 배지 클릭 → 가운데 표의 셀로 스크롤 + 강조. 본문 근거는 문장이 노란 배경.
5. 보류: "답변 보류" 배지 + 이유(문서에 없음 / 모호 / 단위 불일치 / 검증 실패 / 검색 실패) + 어떤 검사가 실패했는지.
6. 오류/시간 초과: 빨간 띠 + 재시도 버튼. 백엔드 없음: 입력창 비활성 + 저장된 결과 안내.

## 상태 설계

| 상태 | 표시 |
|---|---|
| 빈 상태(문서 미선택) | 가운데: "왼쪽에서 문서를 고르세요" + 코퍼스 설명; 오른쪽: 입력창 비활성 |
| 로딩(문서/목록) | 스켈레톤 줄 3개 |
| 실행 중 | 상태 띠 + 경과 시간 타이머(500 ms 간격) + 실행 버튼 비활성 |
| 완료(answered) | 초록 배지 "완료" |
| 보류(abstained) | 회색-주황 배지 "답변 보류" + 사유 |
| 오류/시간 초과/대기열 초과(429) | 빨간 띠 + 메시지 + 재시도 |
| 저장된 결과 | 파란 배지 "저장된 실행 결과 · 2026-10-29 · mt5-small-tabletrace · commit abc1234" |

## 접근성·키보드

- 문서 목록: `role=listbox`, ↑/↓ 이동, Enter 선택. 대표 질문 칩: 버튼. 입력창: Enter 실행, Shift+Enter 줄바꿈 없음(단일 행).
- 모든 상호작용 요소에 `:focus-visible` 윤곽. 색만으로 상태를 구분하지 않음(아이콘+텍스트).
- 표 셀 `title`에 좌표·헤더·단위.

## 시각 원칙

- 바탕 `#f5f6f8`, 글자 `#1d2733`, 강조 `#2b5c8a`, 근거 `#fff1c2`+`#c99a1a` 테두리, 보류 `#8a6d1f`, 오류 `#a4262c`.
- 그라데이션·글로우·장식 아이콘 없음. 시스템 글꼴. 숫자는 등폭 보조 글꼴.
