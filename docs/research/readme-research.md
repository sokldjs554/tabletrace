## TableTrace README에 반영한 구성

1. 한 줄 정의 + 공개 데모 링크 + CI 배지를 **맨 위**에 (SKN27, ragas).
2. 바로 아래 **화면 이미지/시연 GIF**와 "체험 순서 7단계" (SKN27의 영상 → 우리는 Playwright 캡처).
3. "어떤 문제를 푸는가"를 짧게, 그다음 **핵심 기능을 기능·설명·구현 3열 표**로 (SKN27).
4. 데이터 출처·라이선스를 표로, **분할·누수 확인 결과**를 수치와 함께 (KLUE·KorWikiTQ의 데이터 표 + 우리 측정).
5. 모델·학습 방법, 아키텍처·Agent 흐름(Mermaid), 평가 방법.
6. 결과 표는 **모두 저장소 산출물(JSON) 경로를 함께** 적고, 개선되지 않은 결과도 그대로 (SKN20의 단계별 추적을 "정직한 버전"으로).
7. 실패 사례·한계 → 로컬 실행 → 테스트·CI·배포 → **실제 수행 / 미수행 표**.
8. 팀 소개·회고·시장 규모 같은 항목은 1인 연구 프로젝트에 맞지 않아 뺐다. 배지는 CI·라이선스만 둔다(기술 스택 배지 나열 대신 역할 표).
